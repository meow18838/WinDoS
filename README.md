# WinDoS
This proof of concept overloads the desktop until nothing works anymore.

The vulnerability allows making the system completely unresponsive within seconds with low privileges and allowing scripts to do anything while the users can only sit back and wait while even the power button doesn't work anymore. Any antivirus seem to hang and not be able to process anything anymore too. Eicar test file was not deleted. Task Manager doesnt update anymore either. Ctrl + Alt + Del is gone too….

This case was closed by the MSRC as no msrc case so you can now explore this and learn from it.

## Disclaimer:
This Repository contains Code that could be used for malicious purposes, the code is provided for educational purposes only to learn how to protect against such attacks and to find further bugs that can be reported to the corresponding vendor.
